# Accessible Musical Instruments · 无障碍乐器改造

> 项目4：无障碍乐器改造 —— [OpenRD 罕见病开源社区](https://github.com/OpenRDHub)

为肢体障碍的音乐爱好者改造、制作专属乐器。

## 真实处境

许多热爱音乐的肢体障碍者，受限于现有的乐器与演奏形式，难以持续演奏或参与合奏。

## 挑战方向

- 基于 MIDI、3D 打印与 Arduino 等技术
- 面向具体个人改造、制作专属乐器
- 沉淀可复用的改造方案

## 关键词

`肢体障碍` `乐器改造` `MIDI` `3D 打印` `Arduino`
