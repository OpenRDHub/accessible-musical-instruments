# Accessible Musical Instruments · 无障碍乐器改造

> 「罕见·无界」黑客松赛题 · 项目4：无障碍乐器改造
> 由 [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起 · 患者共创 · 一个赛题 = 一个长期开源项目

面向肢体障碍音乐爱好者的乐器改造与定制：基于开源技术，为具体的人改造、制作专属乐器，并沉淀可复用的改造方案。

## 🧭 背景与真实处境

许多热爱音乐的肢体障碍者（含罕见病致肢体功能障碍者），受限于现有的乐器与演奏形式，难以持续演奏或参与合奏。标准乐器为"标准身体"设计，而障碍者的障碍类型、肌力、关节活动度各不相同——通用的"无障碍乐器"并不存在，**个性化改造**才是真实需求；但商业化定制门槛高、价格贵，多数家庭难以负担。

## 🎯 挑战方向

- 基于 **MIDI、3D 打印与 Arduino** 等开源技术，面向具体个人改造、制作专属乐器
- 沉淀**可复用的改造方案**：按障碍类型（上肢 / 下肢 / 单手 / 指关节等）归纳设计模式，让每一次改造的经验帮助下一个人

## 📌 项目状态

赛题已开放，详细需求资料与患者案例将陆续沉淀到社区知识库（本仓库同步更新）。

**改造方向示例**（欢迎讨论）：

- 单手可演奏的笛 / 口风琴支架与指法重映射
- MIDI 化改造：用微动开关、压力、吹气等替代常规按键/弦
- 3D 打印个性化适配件（握把、固定支架、助力结构）

## 🤝 如何参与

适合电子制作 / 3D 建模 / MIDI 与音频编程 / 职业治疗 / 音乐教育背景的朋友；障碍者本人的需求与试奏反馈是项目的核心输入。

- 🐛 [提出问题与需求](https://github.com/OpenRDHub/accessible-musical-instruments/issues)
- 🔧 提交 Pull Request（CAD 模型、代码、改造文档都是贡献）

## ⚕️ 医疗与隐私原则

涉及身体接触的辅具测试应优先评估安全与风险；不得未经授权使用患者姓名、肖像与私人经历。
