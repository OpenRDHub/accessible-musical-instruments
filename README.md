# Accessible Musical Instruments · 无障碍乐器改造

> 「罕见·无界」黑客松赛题 · 项目4：无障碍乐器改造
> 需求发起者：大连 · 周爽（脑瘫患者，星期八乐队成员）· [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)共建 · 一个赛题 = 一个长期开源项目

针对具体个人的肢体条件改造乐队核心乐器（吉他 / 贝斯 / 键盘 / 架子鼓），让肢体障碍音乐爱好者**独立完成完整演奏、真正站上舞台**，并沉淀可复用的改造方案。

## 🧭 发起者的疾病与身体状况

周爽因出生时难产缺氧造成围产期窒息脑损伤，确诊为**脑瘫**。脑瘫核心特征为非进行性中枢性运动障碍与肢体姿势异常——脑部损伤为永久性、不会继续恶化，但长期异常发力与肢体受限会伴随肌肉张力异常、肢体协调不足等问题。

结合本人实际身体状况：

- 无法独立行走，下肢力量与平衡能力不足
- **右手可用**：具备基础力量与控制能力，能独立完成抓握、按压、敲击等动作与日常生活行为
- **左手辅助**：功能偏弱、肌张力偏高、精细动作差，仅能配合右手，无法承担双手协同类精细任务
- **无脚部操作能力**

## ❓ 现实困境

周爽凭借对音乐的热爱加入了星期八乐队，希望通过舞台实现自我价值。但主流乐队乐器全部基于健全人**双手协同、手脚配合**的能力设计：

- **吉他 / 贝斯**：左手按弦、右手拨弦，双手必须高度同步精准配合
- **键盘乐器**：大量和弦需要同时按下两至三个琴键，对灵活度、跨度、同步性要求极高
- **架子鼓**：底鼓依赖脚部踩踏发力，整体演奏逻辑为四肢协同作业

受脑瘫肢体功能障碍影响（肢体不对称、精细动作缺失、手脚协调不足），大量残障音乐爱好者**有热爱、有能力、有意愿，却没有合适的设备**参与乐队演奏——并非缺乏音乐热爱与舞台梦想，而是标准化乐器完全没有适配肢体残障群体的操作逻辑。

## 🎯 三大改造需求（精准适配"右手可用、左手辅助、无脚部操作"）

### 1. 吉他 / 贝斯：减负左手，主力右手

加装**智能辅助压弦设备 / 机械辅助按弦结构**，预设常用流行和弦指法：降低左手按压力度与操作难度，将主要演奏动作集中在右手拨弦、控弦——单手主导、轻辅助即可完成完整弹唱伴奏。

### 2. 键盘：和弦一键集成

将常规流行歌曲的三键、多键和弦**整合为单键触发模式**——单键完整输出标准和弦音色，无需多指同步，单手独立按压即可完成完整和弦伴奏。

### 3. 架子鼓：全手动击打替代手脚配合

**取消脚部底鼓踏板结构**，将底鼓音色、节奏点位全部迁移至手动鼓面 / 手击触发垫——整套鼓组所有节奏点位全部依靠手部击打完成，彻底摆脱脚部依赖，单手/双手轻协同即可独立完成全套演奏。

## 🛠 技术方向

基于 **MIDI、3D 打印与 Arduino** 等开源技术实现（例如：机械辅助按弦结构、MIDI 单键和弦映射、手击电子触发垫），并在改造过程中**沉淀可复用的改造方案**——按障碍类型归纳设计模式，让每一次改造的经验帮助下一个人。

## 💡 项目价值

不仅满足个人音乐热爱与舞台梦想，更为广大脑瘫及肢体受限残障群体提供**可复制、可落地**的乐器适配方案：打破"残障人士无法演奏乐器、无法组建乐队"的固有认知，证明肢体缺陷不阻碍艺术追求，助力无障碍文化艺术普及。

## 🤝 如何参与
