# Accessible Musical Instruments · 无障碍乐器改造（脑瘫患者单手适配）

> 「罕见·无界」黑客松 · 赛题4 · 无障碍乐器改造
> 依据《无障碍乐器改造（脑瘫患者单手适配）产品需求书 V1.0》（2026-10-01）编写 · 需求提出人：周爽（大连，脑瘫患者，星期八乐队成员）· [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)共建

结合「右手可用、左手辅助、无脚部操作能力」的身体特征，针对乐队三大核心乐器进行**无障碍、单手适配、简化操作**改造，彻底打破肢体限制，实现独立演奏，并沉淀可复制、可落地的适配方案。

## 🧭 一、项目背景

**疾病概述**：周爽因出生时难产缺氧造成围产期窒息脑损伤，确诊为脑瘫。脑瘫核心特征为非进行性中枢性运动障碍与肢体姿势异常——脑部损伤永久但不会恶化，长期异常发力与肢体受限会伴随肌肉张力异常、肢体协调不足，继发关节发力不均衡、活动受限等问题。

**需求提出人的具体身体状况**：

| 部位 | 功能状态 |
|---|---|
| 下肢 | 无法独立行走，力量与平衡不足，无脚部操作能力 |
| 右手 | 具备基础力量与控制能力，可独立完成日常生活行为（抓握、按压、敲击） |
| 左手 | 功能偏弱、肌张力偏高、精细动作差，仅能辅助配合右手，无法承担双手协同类精细任务 |

**核心特征一句话：右手可用、左手辅助、无脚部操作能力。**

## ❓ 二、现实困境与行业现状

周爽凭借对音乐的热爱加入星期八乐队，希望通过舞台实现自我价值、传递励志正能量。但主流乐队乐器全部基于健全人「双手协同、手脚配合」设计：

| 乐器 | 原生操作逻辑 | 对脑瘫患者的要求 |
|---|---|---|
| 吉他/贝斯 | 左手按弦、右手拨弦 | 双手高度同步、精准配合 |
| 键盘 | 双手独立控制 | 和弦需同时按 2–3 键，对灵活度、跨度、同步性要求极高 |
| 架子鼓 | 手脚联动 | 底鼓依赖脚部踩踏，整体为四肢协同作业 |

多数脑瘫患者存在肢体不对称、精细动作缺失、手脚协调不足——**并非缺乏音乐热爱与舞台梦想，而是标准化乐器完全没有适配肢体残障群体的操作逻辑**，导致大量残障音乐爱好者有热爱、有能力、有意愿，却无合适设备参与乐队演奏。

## 🛠 三、改造需求与验收标准

| 乐器 | 现有障碍 | 改造方向 | 验收标准 |
|---|---|---|---|
| 吉他/贝斯 | 左手无法独立按弦、换和弦 | 机械辅助按弦 + 预设和弦指法，动作重心移至右手 | 单手主导、轻辅助即可完成完整弹唱伴奏 |
| 键盘 | 无法多指同步按压和弦 | 和弦一键集成，单键触发输出完整和弦音色 | 单手独立按压完成完整和弦伴奏 |
| 架子鼓 | 无法脚部踩踏底鼓 | 取消脚踏，底鼓音色与节奏点位全部迁移至手击触发垫 | 单手/双手轻协同完成全套鼓组演奏 |

- **吉他/贝斯**：加装智能辅助压弦设备/机械辅助按弦结构，预设常用流行和弦指法；降低左手按压力度与操作难度，弱化左手复杂操作，主要演奏动作集中在右手拨弦、控弦
- **键盘**：将常规流行歌曲三键、多键和弦整合为单键触发模式，单键完整输出标准和弦音色；简化演奏逻辑，无需多指同步
- **架子鼓**：取消脚部底鼓踏板结构，将底鼓音色、节奏点位全部迁移至手动鼓面/手击触发垫；整套鼓组全部依靠手部击打完成，彻底摆脱脚部依赖

## 📋 四、非功能需求

| 类别 | 要求 |
|---|---|
| 可复制性 | 方案可复制、可落地，为广大脑瘫及肢体受限群体提供适配参考 |
| 低门槛 | 操作逻辑简化，不增加额外学习负担 |
| 稳定性 | 适应肌张力异常、肢体协调不足的实际情况，避免因异常发力导致误触发 |
| 乐队场景适配 | 满足实际排练与演出场景，而非仅居家练习 |
| 可调节性 | 适配不同肢体功能残障程度的患者（不限于单一用户） |

## 💡 五、项目价值

不仅是满足个人音乐热爱与舞台梦想，更为广大脑瘫及肢体受限残障群体提供可复制、可落地的乐器适配方案——打破「残障人士无法演奏乐器、无法组建乐队」的固有认知，证明肢体缺陷不阻碍艺术追求，助力无障碍文化艺术普及。

## ⚕️ 医疗与隐私原则

涉及身体接触的辅具测试应优先评估安全与风险；不得未经授权使用患者姓名、肖像与私人经历。
